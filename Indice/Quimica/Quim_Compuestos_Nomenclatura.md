## Conceptos clave

### Número de oxidación (NO)

El **número de oxidación** es la carga eléctrica formal que tendría un átomo en un compuesto si todos los enlaces fueran iónicos. Es una herramienta conceptual para formular y nombrar compuestos.

#### Reglas para asignar números de oxidación

1. **Elementos libres** (en su estado elemental): NO = 0. Ej: $H_2$, $O_2$, $Fe$, $S_8$.
2. **Iones monoatómicos**: NO = carga del ión. Ej: $Na^+$ → +1, $Cl^-$ → -1, $Mg^{2+}$ → +2.
3. **Flúor**: siempre NO = -1 en todos sus compuestos.
4. **Oxígeno**: NO = -2 en la mayoría de compuestos. Excepciones:
   - Peróxidos ($O_2^{2-}$): NO = -1 (ej: $H_2O_2$)
   - Superóxidos ($O_2^-$): NO = -1/2
   - Con flúor ($OF_2$): NO = +2
5. **Hidrógeno**: NO = +1 en la mayoría de compuestos. Excepción: hidruros metálicos ($NaH$, $CaH_2$) → NO = -1.
6. **Suma de NO en un compuesto neutro** = 0.
7. **Suma de NO en un ión poliatómico** = carga del ión.

### Compuestos binarios

Son los que contienen **dos elementos diferentes**. Se nombran colocando el nombre del elemento menos electronegativo seguido del más electronegativo, con la terminación adecuada.

#### 1. Óxidos básicos (metal + oxígeno)

Fórmula general: $M_xO_y$

- **Nomenclatura sistemática** (prefijos): $óxido$ + *prefijo* + $de$ + *metal*
  - $Fe_2O_3$ → trióxido de dihierro
- **Nomenclatura Stock** (números romanos): $óxido$ + $de$ + *metal* + *(NO)*
  - $Fe_2O_3$ → óxido de hierro(III)
- **Nomenclatura tradicional**: $óxido$ + *raíz del metal* + *sufijo*
  - $FeO$ → óxido ferroso, $Fe_2O_3$ → óxido férrico

#### 2. Óxidos ácidos (no metal + oxígeno) — también llamados anhídridos

Fórmula general: $NM_xO_y$

- **Tradicional**: $anhídrido$ + *raíz del no metal* + *sufijo* (-oso/-ico) según el NO
  - $SO_2$ → anhídrido sulfuroso (S con +4)
  - $SO_3$ → anhídrido sulfúrico (S con +6)
- **Sistemática**: $óxido$ + *prefijo* + $de$ + *no metal*
  - $SO_2$ → dióxido de azufre
- **Stock**: $óxido$ + $de$ + *no metal* + *(NO)*
  - $SO_2$ → óxido de azufre(IV)

#### 3. Peróxidos

Contienen el grupo $O_2^{2-}$ (ión peróxido). NO del oxígeno = -1.

- $Na_2O_2$ → peróxido de sodio
- $H_2O_2$ → peróxido de hidrógeno (agua oxigenada)
- $CaO_2$ → peróxido de calcio

#### 4. Hidruros metálicos (metal + hidrógeno)

El H actúa con NO = -1.

Fórmula: $MH_x$

- $NaH$ → hidruro de sodio
- $CaH_2$ → hidruro de calcio
- $AlH_3$ → hidruro de aluminio

#### 5. Hidruros no metálicos (no metal + hidrógeno)

Son compuestos volátiles o ácidos hidrácidos en solución acuosa.

- **Hidruros covalentes** (grupos 13-17):
  - $NH_3$ → amoníaco
  - $PH_3$ → fosfina
  - $H_2S$ → sulfuro de hidrógeno
  - $HCl_{(g)}$ → cloruro de hidrógeno
- **Ácidos hidrácidos** (en solución acuosa):
  - $HCl_{(ac)}$ → ácido clorhídrico
  - $H_2S_{(ac)}$ → ácido sulfhídrico

#### 6. Sales binarias (metal + no metal)

Resultan de sustituir el H de un hidrácido por un metal.

Fórmula: $M_aNM_b$

- $NaCl$ → cloruro de sodio
- $CaF_2$ → fluoruro de calcio
- $FeS$ → sulfuro de hierro(II) o sulfuro ferroso

#### 7. Compuestos volátiles (entre no metales)

- $CO$ → monóxido de carbono
- $CO_2$ → dióxido de carbono
- $N_2O_3$ → trióxido de dinitrógeno
- $CCl_4$ → tetracloruro de carbono

### Compuestos ternarios

Contienen **tres elementos diferentes**.

#### 1. Hidróxidos (metal + O + H)

Contienen el grupo $OH^-$ (ión hidróxido o ión oxidrilo).

Fórmula general: $M(OH)_x$

- $NaOH$ → hidróxido de sodio
- $Ca(OH)_2$ → hidróxido de calcio
- $Fe(OH)_3$ → hidróxido de hierro(III) o hidróxido férrico

#### 2. Oxoácidos (H + no metal + O)

Provienen de la reacción de un óxido ácido + agua.

Fórmula general: $H_aNM_bO_c$

- **Sistemática**: $ácido$ + *prefijo* + $oxo$ + *raíz del no metal* + $-(ico)$ + *(NO)*
- **Tradicional** (la más usada): usa prefijos y sufijos según el NO del no metal:
  - $H_2SO_4$ → ácido sulfúrico (S con +6)
  - $H_2SO_3$ → ácido sulfuroso (S con +4)
  - $HNO_3$ → ácido nítrico (N con +5)
  - $HNO_2$ → ácido nitroso (N con +3)
  - $HClO_4$ → ácido perclórico (Cl con +7)
  - $HClO_3$ → ácido clórico (Cl con +5)
  - $HClO_2$ → ácido cloroso (Cl con +3)
  - $HClO$ → ácido hipocloroso (Cl con +1)

#### 3. Oxosales (metal + no metal + O, sin H)

Resultan de sustituir los H de un oxoácido por un metal.

Fórmula general: $M_aNM_bO_c$

- $Na_2SO_4$ → sulfato de sodio
- $CaCO_3$ → carbonato de calcio
- $KNO_3$ → nitrato de potasio
- $Fe_2(SO_4)_3$ → sulfato de hierro(III) o sulfato férrico

> [!EXAMPLE] Regla mnemotécnica para oxosales
> El nombre de la oxosal viene del oxoácido correspondiente:
> - Ácido **sulfur**oso → **sulfit**o de...
> - Ácido **sulfur**ico → **sulfat**o de...
> - Ácido **nitr**oso → **nitrit**o de...
> - Ácido **nitr**ico → **nitrat**o de...
> - Ácido **hipoclor**oso → **hipoclorit**o de...
> - Ácido **perclór**ico → **perclorat**o de...

### Pasos para formular cualquier compuesto inorgánico

1. **Identificar los elementos** que componen el compuesto.
2. **Determinar los NO** de cada elemento usando las reglas.
3. **Cruzar los NO** como subíndices (el NO de uno pasa como subíndice del otro).
4. **Simplificar** los subíndices si es posible (dividir por el MCD).
5. **Verificar** que la suma de NO × subíndices = 0.
6. **Asignar el nombre** según el sistema solicitado.

### Pasos para nombrar cualquier compuesto

1. Identificar de qué **tipo de compuesto** se trata (binario/ternario, óxido/hidruro/etc.).
2. **Calcular el NO** del elemento variable.
3. Elegir el **sistema de nomenclatura** (IUPAC sistemática, Stock o tradicional).
4. Aplicar las **reglas específicas** de ese tipo de compuesto.

---

## Fórmulas importantes

- **Carga total en compuesto neutro**: $\sum (NO_i \times subíndice_i) = 0$
- **Carga en ión poliatómico**: $\sum (NO_i \times subíndice_i) = \text{carga del ión}$
- **Regla de la cruz**: $A_a B_b \rightarrow A^{a} \text{ y } B^{b}$ → NO(A) como subíndice de B y viceversa
