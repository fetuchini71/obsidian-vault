|---|--------|------|

## 📚 Libros de Texto — Comparativa

### 🥇 Chang, Raymond — *Química* (10a/11a ed)
| Aspecto | Detalle |
|---------|---------|
| ⭐ Rating | ★★★★★ — El más recomendado para 1er año |
| 💪 Fortaleza | Claridad pedagógica, ejemplos graduales, progresivo |
| ⚠️ Debilidad | Menos profundidad en física-química |
| 🎯 Ideal si... | **Te cuesta química** — es el más didáctico |
| 📥 PDF | Library Genesis o buscar "Chang Química 10ed PDF" |

### 🥈 Brown, Theodore — *Química: La Ciencia Central* (11a/13a ed)
| Aspecto | Detalle |
|---------|---------|
| ⭐ Rating | ★★★★☆ — El más completo y equilibrado |
| 💪 Fortaleza | Cobertura equilibrada teoría + problemas |
| ⚠️ Debilidad | A veces denso, salta entre temas |
| 🎯 Ideal si... | Querés el estándar universitario completo |
| 📥 PDF | [Archive.org — 11a ed](https://archive.org/details/qumicalacienciacentral-11avaedicion) |

### 🥉 Petrucci, Ralph — *Química General* (10a ed)
| Aspecto | Detalle |
|---------|---------|
| ⭐ Rating | ★★★★☆ — El más riguroso |
| 💪 Fortaleza | Más ejercicios, más profundidad matemática |
| ⚠️ Debilidad | Más pesado de leer, menos visual |
| 🎯 Ideal si... | Ya tenés base y querés profundizar |
| 📥 PDF | [PDF descarga directa](https://quimica247403824.files.wordpress.com/2018/11/quimica_general_petrucci.pdf) |

### 📘 Atkins, Peter — *Principios de Química*
| Aspecto | Detalle |
|---------|---------|
| ⭐ Rating | ★★★☆☆ — Buen complemento conceptual |
| 💪 Fortaleza | Enfoque moderno, explica el "por qué" |
| ⚠️ Debilidad | Muy teórico para empezar |
| 🎯 Ideal si... | Querés entender el fundamento detrás de todo |

> **💡 Estrategia:** Arrancá con **Chang** (más claro), usá **Brown** como referencia principal, **Petrucci** para ejercitar.
