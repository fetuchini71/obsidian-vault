**Por qué:** El libro más alineado al programa típico de AGA en universidades argentinas. Escrito específicamente para ingeniería. Cubre exactamente los temas de primer año con ejercicios resueltos paso a paso. PDF en idoc.pub.

**Adriana Bonamusa, Lucotti, del Puerto** — CEIT

**Por qué:** El clásico "libro de la UTN". Flaco, directo, teoría justa y ejemplos resueltos detalladamente. PDF en Scribd/pdfcookie.

### #3 — Geometría Analítica
**Charles H. Lehmann** — Ed. Limusa

**Por qué:** El libro de geometría analítica por excelencia en Argentina. Cónicas, rectas, planos y lugares geométricos con claridad didáctica. No cubre matrices, pero para geometría pura es imbatible. PDF en Archive.org.

### #4 — Álgebra y Geometría: Una Manera de Pensar
**UNLP** — Acceso abierto

**Por qué:** Producido por la UNLP. Gratuito. Capítulos de números complejos, polinomios y espacios vectoriales muy logrados.
🔗 https://libros.unlp.edu.ar/index.php/unlp/catalog/book/1289

### #5 — Álgebra Lineal — Libro para el Estudiante
**Mariana Pérez (UNAHUR)** — Gratuito

**Por qué:** Material didáctico moderno para universidad argentina. Progresión cuidada con problemas contextualizados en ingeniería.
🔗 https://unahur.edu.ar/wp-content/uploads/2022/03/Algebra_Lineal_Libro_ESTUDIANTE__Mariana-Perez.pdf

## 💡 TIPS POR TEMA DIFÍCIL

### Números Complejos — Dificultad: Media
- Dividir: multiplicar num/den por conjugado
- Raíces n-ésimas → pasar a polar SIEMPRE (Moivre da n soluciones)
- Dibujar el plano complejo ayuda enormemente

### Matrices — Dificultad: Alta
- Error típico: AB ≠ BA (orden importa)
- Inversa 3x3+: Gauss-Jordan [A\|I] → reducir
- Verificar siempre A·A⁻¹ = I

### Determinantes — Dificultad: Media-Alta
- Sarrus solo para 3x3. Para 4x4+ → triangular por Gauss
- Si 2 filas/columnas iguales o proporcionales → det = 0

### Sistemas de Ecuaciones Lineales — Dificultad: Media
- det(A) ≠ 0 → SCD. det(A) = 0 → analizar rangos
- Escalonar CON el parámetro, tratar como número

### Vectores R2/R3 — Dificultad: Media
- Escalar (·) → NÚMERO (ángulos, proyecciones)
- Vectorial (×) → VECTOR (área, perpendicular)
- Mixto (u·(v×w)) → NÚMERO (volumen)

### Rectas y Planos — Dificultad: Alta
- Recta: punto + vector dirección
- Plano: punto + 2 vectores directores (o punto + normal)
- Distancia punto-plano: fórmula directa

### Cónicas — Dificultad: Alta
- **Completar cuadrados** es la habilidad #1. Practicar hasta que salga automático.
- Ax² + Cy² + Dx + Ey + F = 0:
  - A y C igual signo e iguales → circunferencia
  - A y C igual signo diferentes → elipse
  - A y C signo opuesto → hipérbola
  - A=0 o C=0 (no ambos) → parábola
